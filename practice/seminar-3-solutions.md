## Q1 · Housing: Qd = 60,000 − 20p, Qs = −20,000 + 30p

**a)** 60,000 − 20p = −20,000 + 30p → 80,000 = 50p → **p\* = €1,600, Q\* = 28,000**
Demand reaches 0 at p = 3,000; supply starts at p = 20,000/30 = 666.67.

- CS = ½(3,000 − 1,600)(28,000) = **€19.6m**
- PS = ½(1,600 − 666.67)(28,000) = **€13.07m**
- TS = €32.67m

**b)** Ceiling €1,000 → Qs = 10,000, Qd = 40,000 → shortage 30,000. WTP at Q = 10,000: p = 2,500.

- CS = (2,500 − 1,000)(10,000) + ½(3,000 − 2,500)(10,000) = **€17.5m**
- PS = ½(1,000 − 666.67)(10,000) = **€1.67m**
- DWL = ½(2,500 − 1,000)(28,000 − 10,000) = **€13.5m** → yes, there is a deadweight loss

**c)** More inelastic supply → fewer flats withdrawn → smaller quantity loss → the lower rent dominates → **more beneficial** for families. Here supply is fairly elastic and renters as a group lose (19.6m → 17.5m).

**d)** Yes. Only 10,000 flats; the marginal renter would pay up to €2,500 → side payments, key money, illegal sub-letting.

**e)** Lower returns → less investment in new housing and maintenance → lower quality; long-run supply falls further.

## Q2 · Delivery workers: Ld = 6,000 − 4w, Ls = 2,000 + w

**a)** 6,000 − 4w = 2,000 + w → **w\* = €800, L\* = 5,200**

**b)** Minimum wage €1,000 → Ld = 2,000, Ls = 3,000 → **unemployment = 1,000** (job destruction = 5,200 − 2,000 = 3,200)

**c)** Mixed: the 2,000 employed earn €200 more; 3,200 lose their job. Worker surplus falls ≈ €2.88m → €2.0m (assuming the jobs go to the lowest-reservation-wage workers); firms' surplus €1.82m → €0.5m.

**d)** More elastic labour **demand** → more job destruction. More elastic demand **and** supply → more unemployment.

## Q3 · Apples: Qd = 200 − 2p, Qs = 3p

**a)** 200 − 2p = 3p → **p\* = 40, Q\* = 120** · CS = ½(100 − 40)(120) = **3,600** · PS = ½(40)(120) = **2,400** · TS = 6,000

**b)** Quota 80 → price from demand: 80 = 200 − 2p → **p = 60**. Supply price at 80 = 26.67.
PS = (60 − 26.67)(80) + ½(26.67)(80) = **3,733** (↑ from 2,400) · CS = **1,600** · DWL = ½(60 − 26.67)(40) = **667**

**c)** Inelastic demand → price jumps a lot when Q is cut → producers better off. Elastic demand → price barely rises → producers lose.
