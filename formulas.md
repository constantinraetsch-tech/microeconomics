# Formula sheet

## Topic 1 – Introduction

| What | Formula / rule |
|---|---|
| Opportunity cost on a PPF | OC(x) = units of y given up for 1 more x = \|slope\| |
| Reciprocal rule | OC(y) = 1 / OC(x) |
| Linear PPF from time | a·X + b·Y = Total → Y = Total/b − (a/b)·X  (HAL26: 3M + 12P = 120) |
| Joint PPF | Start at max of the vertical good. The producer with the **lowest OC of the horizontal good** switches first → kink → then the other |
| Comparative advantage | Lower opportunity cost. Trade price must lie **between** the two OCs |
| HHI | HHI = Σ sᵢ² (shares in %), range ~0 → 10,000 |
| Minimum HHI with n firms | 10,000 / n (4 firms: 2,500 · 3 firms: 3,333.3) |
| EU merger safe zones | HHI < 1,000 · 1,000–2,000 with Δ < 250 · > 2,000 with Δ < 150 |
| Compound growth | R₅ = R₀ · (1 + g)⁵ |

## Topic 2 – Market analysis

| What | Formula / rule |
|---|---|
| Equilibrium | Qd = Qs → solve p\*, plug in for Q\* |
| Price elasticity of demand | ε = %ΔQ / %ΔP = (ΔQ/ΔP)·(P₀/Q₀) — use **initial** values |
| Point elasticity | ε = Q'(p) · p / Q(p) |
| Linear demand Q = a − bp | ε = −bp / (a − bp) · max revenue at **p = a/2b** (ε = −1) |
| Revenue after a price change | R₁/R₀ = (1 + %ΔP)(1 + %ΔQ) |
| Combined effects | %ΔQ_X = ε_own·%ΔP_X + ε_cross·%ΔP_Y |
| Cross-price elasticity | ε_XY = %ΔQ_X / %ΔP_Y → > 0 substitutes, < 0 complements |
| Income elasticity | ε_R = %ΔQ / %ΔI → > 1 luxury, 0–1 necessity, < 0 inferior |
| Price elasticity of supply | ε_S = %ΔQs / %ΔP (≥ 0) |
| Market demand | Horizontal sum of individual demands (× number of consumers), only where Q ≥ 0 |
| Consumer surplus (linear) | CS = ½ (p_choke − p\*) · Q\* |
| Producer surplus (linear) | PS = ½ (p\* − p_min) · Q\* — **trapezoid** ½(Qs(0) + Q\*)·p\* if supply starts on the Q-axis |

### Revenue test

| Demand | Price ↑ | Price ↓ |
|---|---|---|
| Inelastic (\|ε\| < 1) | Revenue ↑ | Revenue ↓ |
| Unit (\|ε\| = 1) | same | same |
| Elastic (\|ε\| > 1) | Revenue ↓ | Revenue ↑ |

## Topic 3 – Interventions

| Policy | Traded Q | Areas |
|---|---|---|
| Price ceiling (below p\*) | Qs | CS = (WTP at Qs − p_max)·Qs + ½(p_choke − WTP)·Qs · PS = triangle under p_max · DWL = ½(WTP − p_max)(Q\* − Qs) |
| Price floor (above p\*) | Qd | CS = triangle above p_min · PS = (p_min − supply price at Qd)·Qd + triangle below |
| Production quota (below Q\*) | quota | Price read from **demand** at the quota; same areas as a floor at that price |
| Minimum wage | Ld | Job destruction = L\* − Ld · Unemployment = Ls − Ld |

Elasticity rules: ceiling helps consumers more with **inelastic supply** · producers gain from a quota/floor with **inelastic demand** · minimum wage destroys fewer jobs with **inelastic labour demand**; unemployment grows with more elastic demand **and** supply.
